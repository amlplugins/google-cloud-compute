# @amlplugins/google-cloud-compute

Native `@google-cloud/compute` SDK re-exported under the `@amlplugins` namespace.

> Compute Engine.

## Install

```bash
npm install @amlplugins/google-cloud-compute
```

## Use

```ts
import { /* named exports from @google-cloud/compute */ } from "@amlplugins/google-cloud-compute";
// or
import sdk from "@amlplugins/google-cloud-compute";
```

Built and published by GitHub Actions on every push to `main`.

Part of the amlplugins family — see https://github.com/amlplugins.
